# PRD: Landing Page Visual Design — Moniké

## 1. Purpose

Create a dark, cinematic landing page for the brand **Moniké**.

The page should visually follow the provided AI-generated concept: layered dark fantasy artwork, transparent logo, left-side navigation, central hero CTA, bottom visual category cards, and social links.

The final page must be implemented with real HTML/CSS layers, not as one flat image.

## 2. Brand Direction

Brand name:

```txt
Moniké
```

Visual tone:

```txt
dark
black
gold
mystical
artistic
cinematic
elegant
personal
dreamlike
```

Primary visual impression:

```txt
A black-and-gold artistic world with travel, memories, animals, creativity, and personal storytelling.
```

## 3. Core Layout

Route:

```txt
/
```

The landing page should include:

```txt
Full-screen background image
Transparent Moniké logo
Left-side transparent navigation
Central hero text block
Central CTA button
Bottom five category cards
Bottom-left social icons
Optional handwritten/signature decoration
```

The layout should feel like one composed poster, but every interactive/text element must be real HTML.

## 4. Color System

Use black as the dominant base.

Required color tokens:

```css
:root {

  --color-black-soft: #0A0A0A;

  --color-focus: #E8D59A;

```

## 5. Contrast Requirements

The design must target WCAG AA readability.

Minimum contrast rules:

```txt
Normal text: minimum 4.5:1 contrast ratio
Large text: minimum 3:1 contrast ratio
Interactive borders/focus indicators: minimum 3:1 contrast ratio
```

Rules for gold on black:

```txt
Use #D6B76A or #E8D59A for normal readable text.
Use #B88A36 only for large decorative text, borders, dividers, and hover accents.
Do not use #8A6424 for small text.
Do not place gold text directly over busy image areas without a dark overlay.
```

All text placed over images must have one of:

```txt
dark gradient behind it
dark radial overlay behind it
text-shadow plus darkened background area
semi-transparent black panel
```

Preferred overlay:

```css
background: linear-gradient(
  90deg,
  rgba(0, 0, 0, 0.82),
  rgba(0, 0, 0, 0.42),
  rgba(0, 0, 0, 0.72)
);
```

Use one main full-page background image.

Required assets:

```txt
background-mobile.jpg
```

Background behavior:

```css
background-size: cover;
background-position: center;

```

Desktop:

```txt
The main figure / visual focus should sit center-right.
The left side must remain dark enough for navigation.
The bottom must remain dark enough for cards and social links.
```

Mobile:

```txt

Keep the main subject visible.
Keep the hero text readable.
```

## 16. Image Layering

Required visual layers:

```txt
Layer 1: black background color fallback
Layer 2: full-screen background image
Layer 3: dark gradient overlay
Layer 4: logo, menu, hero, cards, social links
```

Overlay requirement:

```css
.landing-overlay {
  position: absolute;
  inset: 0;
  background:
    radial-gradient(circle at 50% 45%, rgba(0,0,0,0.12), rgba(0,0,0,0.68) 72%),
    linear-gradient(90deg, rgba(0,0,0,0.82), rgba(0,0,0,0.28), rgba(0,0,0,0.76));
  z-index: 5;
}
```

All content should sit above overlay:

```css
z-index: 20;
```

## 17. Responsive Requirements

Desktop:

```txt
Logo top-left.
Menu left side.
Hero center-lower.
Cards bottom row.
Social icons bottom-left.
```

Tablet:

```txt
Logo smaller.
Menu may remain left if enough width.
Cards can become horizontal scroll.
Hero moves slightly upward.
```

Mobile:

```txt
Logo top-left or top-center.
Navigation becomes hamburger.
Hero remains centered and readable.
Cards become horizontal scroll.
Social links remain visible but must not overlap cards.
```

Mobile minimum support:

```txt
360px width
667px height
```

## 18. Accessibility Requirements

Required:

```txt
All text must meet WCAG AA contrast.
All clickable cards must be links.
All links and buttons must have focus-visible styles.
All images must have alt text unless decorative.
Mobile menu button must use aria-expanded.
No text should be image-only unless decorative.
CTA must be keyboard accessible.
Social links must have aria-label values.
```

Required labels:

```txt
Instagram link aria-label: Instagram Moniké
Facebook link aria-label: Facebook Moniké
Mobile menu button aria-label: Otevřít menu
```

Focus style:

```css
:focus-visible {
  outline: 2px solid var(--color-focus);
  outline-offset: 4px;
}
```

## 19. Do Not Implement

Do not include:

```txt
Red annotation rectangles
Visible layout guides
Logo box background
Menu box background
Low-contrast dark gold text
Text baked into the background image
Large UI library
Tailwind requirement
Complex animations
Video background
```

## 20. Acceptance Criteria

Landing page is accepted when:

```txt
The brand name is Moniké.
The page uses black as the dominant color.
Readable text uses accessible gold or soft white.
Logo appears transparent with no container.
Left menu appears as transparent text links.
Menu hover and focus states work.
Hero block is centered and readable.
CTA button is visible and keyboard accessible.
Five bottom category cards are visible and clickable.
Card text remains readable over images.
Social links appear and are accessible.
The page is responsive on desktop, tablet, and mobile.
No red annotation boxes appear.
All important text is real HTML, not baked into images.
```
